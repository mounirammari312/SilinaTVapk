VLC cell surface = VLCVideoLayout (TextureView mode — the app's one-active-surface rule, no z-order fights with the cell's Compose overlays); audio = int volume scale (0/100). Graceful degradation: if LibVLC cannot initialize on a device (16KB-page natives / lite build), `vlcUnavailable` bows the rung out and the chain walks on — no crash, ever.
- **THE FIX — LAYER 2, THE AUDIO DECODER ECONOMY** (`MultiScreenGrid.claimsAudio`, pure/JVM-tested): at most ONE cell — the focused one — ever claims an AUDIO decoder instance. A non-focused EXO cell disables its audio TRACK TYPE entirely (`TrackSelectionParameters.setTrackTypeDisabled(TRACK_TYPE_AUDIO, true)` — set BEFORE the first frame, so no audio renderer is ever initialized, nothing for a shallow codec farm to refuse); a focus swap flips the flags in place (a live track re-selection — instant, no player rebuild, no stream restart — the sound joins the newly focused cell exactly as before). VLC cells are muted by volume only (software audio — no farm to exhaust). On a 2-audio-decoder box, the 4-cell grid now asks for ONE audio decoder instead of four.
